# assets/

Place the following files here:

- `icon.ico` — Windows application icon (256x256 recommended, multi-size ICO)
- `icon.png` — PNG version for taskbar/about screen

## Creating an icon

You can create a free icon at:
- https://favicon.io/favicon-generator/  (text → ICO)
- https://www.icoconverter.com/          (PNG → ICO)

Recommended: Use the Kometa cyan color (#0bc8e0) with a lightning bolt ⚡ or "K" letter.
